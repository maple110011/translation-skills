# 设计决策存档

这里放**为什么**：做过的取舍、被否掉的方案、踩过的坑与证据。

操作手册不在这里——流程在 `skills/*/SKILL.md`，细则在 `skills/*/references/`。三层怎么分工，见仓库根 [MAP.md](../MAP.md)。

## 规矩

- 文件名 `YYYY-MM-主题.md`，中文主题，一眼看出改了什么。
- 一篇记一件事。方案后来变了，**新开一篇**，在这篇顶部标「已被 xxx 取代」，不要就地重写——决策记录的价值是留下当时的判断。
- 只增不改。发现记错了就补一段「后记」，删掉反而容易重犯。
- 证据要能复核：贴实测命令、返回码、样本文件名，别只写结论。
