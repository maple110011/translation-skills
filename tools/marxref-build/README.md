# 马恩引文索引构建脚本（仅代码）

本目录**只包含用于构建句级索引的 Python 脚本**，共 27 个 `.py`，约 160 KB，全部是代码、注释与 docstring。

## 这里没有什么

**不包含任何马恩原著文本。** 具体说，以下一律不在这个目录、也不在本仓库里：

- 《马克思恩格斯文集》（人民出版社 2009）的中文译文，包括任何整句、段落、章节；
- MECW 英文版原文，以及从 MARX-ZH-CN 等站点抓取的 HTML／纯文本；
- 各卷 PDF、分页文本、页码映射产物；
- 句级语料 `corpus/*.jsonl`、英文标题索引 `index/*.jsonl`、句级对齐表、任何由原文衍生的中间文件；
- 索引成品本身（约 73k 句的检索库）。

脚本里出现的《资本论》《马克思恩格斯文集》等只是文档字符串里的书名，不是原文引语；中文长句均为算法说明、踩坑记录与参数注释。

## 这些脚本做什么

`fetch_*` / `index_*` 取篇目元数据 → `build_*` / `make_*` / `map_*` 按卷建中文段落库 →
`align*` / `locate*` / `page_map.py` 做英中句级对齐与印刷页码定位 → `finalize.py` /
`resolve_*` / `disambiguate.py` 收尾 → `engine.py` / `server.py` / `cli.py` / `client.py` /
`quotes.py` / `article.py` 提供检索与接入。脚本假定运行时同级目录下有 `corpus/`、`index/`、
`pdf/` 等语料目录（多数以 `os.path.dirname(os.path.abspath(__file__))` 为根）。

**这些目录不在仓库里**，所以直接在本目录运行会缺数据。脚本是构建流程的存档，需要使用者自备语料。

> 注意：`fetch_mecw.py` / `fetch_pdf.py` / `index_mecw.py` 运行时会从外部站点抓取马恩原著文本。
> 它们只是抓取工具，不含文本；但是否抓取、抓取后如何使用与分发，授权责任在使用者。
> 本仓库不提供、也不代管任何语料。

## 状态：有待进一步优化

这是一套为特定项目写的工作脚本，**尚未工程化**，已知待办包括：

1. **覆盖不全**：第 8 卷（《资本论》手稿选编，中文为摘选、缺数字锚，三种对齐方案均不可靠）与第 9 卷（语料源缺该卷 HTML，只能从 PDF 抽）未进索引；当前实际覆盖 8 卷。
2. **对齐精度有限**：作者自估约四分之一中文句存在句级错位风险，需逐条人工核对；`article.py` 的 replace 模式会删掉英文原句且无标记可查。
3. **参数硬编码**：页码跳跃上限 `PAGE_LIMIT` 需按卷手调；卷次—年份映射、`works.csv` 的 `@z=n` 偏移等写在代码或数据文件里，换版本要改。
4. **外部源不稳**：依赖 MARX-ZH-CN GitHub 仓库与 hf-mirror 数据集的可用性，没有固定版本号或内容哈希；`index_mecw.py` 靠 Range 请求探测篇目，卷号跳号需特殊容忍。
5. **无测试**：仅有一个 `test_article8.py` 探针，没有回归测试；`export_web.py` 单文件网页作者标注「默认不维护」。
6. **路径约定未抽象**：语料目录与脚本同级，未做成配置项，换机器要按原结构摆放。

优化时请只提交脚本代码，不要提交语料、索引或任何原文片段——仓库根目录的 `.gitignore`
已挡住 `_marx_ref/`、`*.pdf`、`*.zip` 等，但新增的数据文件名仍可能漏网，提交前用
`git status` 与 `git check-ignore` 复核。
