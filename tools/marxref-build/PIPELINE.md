# 马恩引文定位 · 后台服务

英文文献里的马恩引文 → 《马克思恩格斯文集》的中文译文、章次、页码。

形态是**一个常驻程序 + HTTP 接口**，不含前端界面。网页、桌面工具、批处理脚本都通过它接入。
给人看的接入说明见 `接口使用说明.md`；本文件是技术细节与建库管线。

### 没做的两卷，原因不同

**第 9 卷（《反杜林论》《自然辩证法》）**：语料仓库 `MARX-ZH-CN` 里没有这一卷的 HTML，
`docs/MEA`、`epub/MEA.epub` 都只到 1—8、10，第 9 卷只能从 PDF 抽。2026-11-19 补下载了
这一卷（`fetch_pdf.py` 的 JOBS 已加 `9`，29 536 112 字节，`pdf/mea9.txt` 在位），
抽出来是**扫描层 OCR**，不是排版文本：

- 一页 700 字约 10 处错：`：`→`z`、`，`→`$`、`宇宙`→`字窗`、`缺陷`→`缺陆`、`徭役`→`德役`；
- 行被硬折，引文块的缩进与正文段首缩进混在一起，页码只有 692/766 页能干净取出；
- 拿《全集》第20卷（`docs/MEW-ZH/20`，干净 HTML）顶替也不行——**两套校订**：
  同一句文集写「不是由魔术师的三两句话所证明的」，全集写「不是魔术师的三两句话所能证明的」，
  300 字窗相似度 0.79。换底本就等于把引文换掉。

结论：**能定位、不能逐字照抄**。要真补这一卷，得先有第 9 卷的干净电子文本（正版电子书或更好的 OCR），
代码不是瓶颈。

**第 8 卷（《资本论》手稿选编）**：试过，放弃。中文这卷是**摘选**——一段中文对应英文手稿
任意位置的一小段，小标题（[货币的产生和本质] 之类）是编译局后加的，英文里没有。
三条路都试过，都不可靠：

1. 逐篇独立滑窗找位置 → 数字 F1 得分全部撞到 1.00，窗口把整屏数字包进去，没有区分度；
2. 整组单调 DP（对称跳段代价）→ 数字一致率 0.1%，等于随机；
3. 非对称跳段代价 + 对角先验 → 抽检「资本主义生产以前的各种形式」，配到的是讲商品交换的段落。

2026-11-19 又补测了「放开跳段」这条：把段落级 DP 的 `skip_cost` 从 1.4 一路压到 0.02
（等于允许任意跳），1857—58 组三篇的数字一致率仍是 1/11、1/3、1/5，与
`vol8_sent.disabled` 的 10% 持平。**根因不是跳段代价，是粒度**：摘选里一段中文常常只是
英文一大段里的一句，实测一对「中文 49 字／英文 1283 字符」= 26:1。段落对段落的任何 DP
都注定配不上；要做得走**句级 + 自由跳**，代价远大于收益。

按既定原则「宁可说不知道，也不指一段错的中文」，这两卷都不进索引。
`corpus/vol8_sent.disabled` 是当时产物，保留备查。

### 页码怎么来的

各卷 PDF 从 `hf-mirror.com` 的 `VoiceOfML/Teachers` 数据集下载（`fetch_pdf.py`），
`pdftotext -layout` 后每页末尾的独立数字行即印刷页码。段落级锚定率 88—93%，
句子页码按句在段内的字符比例插值。

**一个坑值得记**：跳跃上限（`PAGE_LIMIT`）必须按卷调。第 3 卷放 2600 字时，
页码抽检只有 81%（最大偏差 181 页）；收到 1200 字后升到 98%。原因是有几篇初稿与定稿
文字重复，游标被带到后面去了。

## 2. 运行与接入

### 2.1 常驻服务（主形态）

```bash
start_service.bat                       # Windows：后台启动并自检，默认 8080
python server.py --host 0.0.0.0 --port 8080     # 或直接命令行
python server.py --token s3cret --max-batch 500 # 可选：鉴权、批量上限
```

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/healthz` | 健康检查，免鉴权 |
| GET | `/v1/meta` | 卷列表、句数、页码覆盖 |
| GET | `/v1/match?q=...` | 单条查询（浏览器可直接试） |
| POST | `/v1/match` | 单条：`{"text": "...", "topk": 3, "volumes": [5,6]}` |
| POST | `/v1/match/batch` | 批量：`{"texts": ["...", "..."], "topk": 1}` |
| POST | `/v1/quotes` | 只抽取 Markdown 引文，不匹配 |
| POST | `/v1/article` | **整篇 Markdown：抽取 → 匹配 → 回填** |
| GET | `/v1/openapi.json` | 机器可读描述 |

错误一律 JSON：400 参数、401 未鉴权、404 路径、413 批量超限、500 内部。

长期部署建议用「任务计划程序」跑 `pythonw server.py ...`，勾选“不管用户是否登录都运行”，
比双击 bat 稳，重启后自动恢复。详见 `接口使用说明.md`。

#### 文章级：一篇稿子一次处理

```json
POST /v1/article
{"markdown": "<整篇 Markdown>", "mode": "annotate"}
```

返回 `annotated`（回填好的 Markdown）、`items`（逐条核对信息）、`stats`。
`mode=annotate` 保留英文并列中文（默认，安全）；`mode=replace` 直接替换英文。
已标过 `【中译】` 的位置会跳过，可重复跑。

命令行等价物：`python article.py paper.md` → `paper.zh.md` + `paper.report/report.csv`。

### 2.3 单文件网页（可选，默认不维护）

`export_web.py` 仍可生成 `dist/马恩引文定位.html`（8.3 MB，双击即用，数据内嵌）。

## 3. 数据与管线

```
raw/mea{N}/*.html   raw/mecw{N}/*.html          （MARX-ZH-CN 仓库，按篇一 HTML）
        │ build_corpus.py
        ▼
corpus/mea{N}.jsonl  corpus/mecw{N}.jsonl       块级语料
        │
        ├─ build_vol.py     资本论三卷：按章号自动配对
        ├─ build_works.py   选编卷 1—4：按 works.csv 的显式映射
        ├─ make_letters.py  第 10 卷：按「日期 + 收信人」归并
        ▼
corpus/vol{N}_sent.jsonl                        句级索引
        │ page_map.py + finalize.py（PDF 印刷页码）
        ▼
corpus/vol{N}_sent.jsonl（补 page 字段）
        │
        ├─ engine.py ── server.py / client.py   接口
        └─ export_web.py ── dist/*.html         单文件网页（可选）
```

### 三条不同的建库路径

| 卷 | 脚本 | 配对依据 |
|---|---|---|
| 5、6、7 | `build_vol.py` | 中文篇目带「第X章」、MECW 带 `Ch. N`，按章号自动配对 |
| 1—4 | `build_works.py` | `works.csv` 里的作品级映射（人工逐条核过） |
| 10 | `make_letters.py` + `build_works.py` | 中文标题给发信人、正文日期行给日期；英文 `Letter to X, Month D, YYYY` |

资本论三卷的自动配对有两个坑：**篇标题页里装着该篇第一章的正文**（段落数 > 3 就要按顺序
承接未配对的英文章，纯标题页跳过）；**过滤序言时不能用「含『第』字」判**——「第二版序言」
会被误判成第一章。

### works.csv 的写法

选编卷没有章号可依，全靠这张表。支持五种写法：

| 写法 | 含义 | 例子 |
|---|---|---|
| `T:篇名` | 按标题子串查（找不到退回模糊匹配） | `T:The Poverty of Philosophy` |
| `T:a > b` | 先找含 a 的，再在其中挑含 b 的 | `T:The German Ideology > Volume 1` |
| `R:卷:起-止` | 直接指定文件号区间 | `R:24:11-11` |
| `L:文件,文件` | 直接列文件名 | `L:MECW23-002.html,MECW23-055.html` |
| `P:卷-文件:起-止` | 指定单个文件的**段落**区间 | `P:27-036:73-113` |
| `X:原因` | 英文底本缺失，显式标记跳过 | `X:MECW 27 未收 1895 年导言` |

后缀 `@z=n` 表示跳过中文前 n 段。**《共产党宣言》必须用这个**：中文从 1872 年序言开始，
英文底本从「一个幽灵」开始，不跳会让正文全错位（中文正文起点是第 58 段）。
《哥达纲领批判》同理（`@z=11`，前面是给白拉克的信）。

`P:` 是给语料仓库的「聚合页」用的——它常把多篇序跋塞进同一个 HTML
（`MECW27-036` 里装着 1845 年序言、1887 年美国版序言、1892 年德文版序言三份）。

### 定位精度

段级只用来圈范围，定位靠句级。英文一个 `<p>` 常常等于中文好几段，
点对点映射在体例差异处必然失真。页码按句子在段内的位置插值，
只用段起始页在跨 4 页的长段落里会差出很远。

## 4. 实测

页码准确率用金标准校验：拿中文句去 PDF 全文里查真实印刷页，再和映射结果比。

| 卷 | 英文句 | 配对率 | 页码锚定 | 页码 ±1 页内 |
|---|---|---|---|---|
| 1 | 12712 | 88% | 91.7% | 55/55 |
| 2 | 8515 | 93% | 93.0% | 54/54 |
| 3 | 6858 | 89% | 88.2% | 52/54 |
| 4 | 6269 | 93% | 93.2% | 55/55 |
| 5 | 8931 | 92% | 90.4% | 51/51 |
| 6 | 7126 | 93% | 94.6% | 52/52 |
| 7 | 11586 | 91% | 88.1% | 53/53 |
| 10 | 11205 | 75% | 90.5% | 44/48 |

**注意「配对率」不等于「正确率」。** 配对率只说明句子被配上了一个中文句，不说明配对了。
用数字锚做独立检验（2960 个含两个以上数字的句子）：**62.3% 数字完全一致**，
12% 部分一致（多为中文把一句拆成两句），26% 中文句里根本没有这些数字——
后者一部分是《资本论》第一章的公式体例差异（英文写出数值，中文用 `z量商品A＝u量商品B`），
一部分是真的配错了段。**保守估计四分之一的中文句存在错位风险，必须人工核对。**

第 10 卷配对率只有 75%，明显低于其他卷：同日多封信时只能靠发信人和篇幅猜，会错配。

## 5. 加一卷要做什么

1. 下载该卷中文 HTML（`docs/MEA/{卷}/`）与对应 MECW HTML（`en/MECW/{卷}/`）
2. `build_corpus.py` 的 `run()` 生成两个 jsonl
3. 建映射：
   - 章号能对上（资本论）→ `build_vol.py` 加一行；
   - 选编卷 → `works.csv` 里逐篇填 `T:` / `R:` / `P:`；
   - 书信 → `make_letters.py`
4. `page_map.py {卷号}` + `finalize.py` 补页码（需要该卷 PDF）

新增卷不用改代码——`server.py` 启动时扫描 `corpus/vol*_sent.jsonl`，新卷自动进索引。

索引 MECW 篇目用 `index_mecw.py`（Range 请求只取文件头，全 50 卷约 6700 篇）。
注意 MECW 编号会跳号，空号容忍必须 ≥6，否则整卷会被截成一两篇。
