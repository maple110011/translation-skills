# 五条硬规则的边界与判例

规则本身很短，难的是边界。这份文档回答"这里到底算不算增删""引用到底译不译"这类具体判断。每条给正例与反例，反例是实际翻译里最常见的错法。

---

## 规则 1：忠实原文，不增不删

### 允许的

**补足汉语必需的语法成分。** 英文没有量词、没有"的"、主语常省略，中文补上是语法要求，不算增。

> 源：The rate of profit fell.
> 译：利润率下降了。
> （"了"是时态补偿，不算增。）

**把隐含的逻辑关系显性化，但只用原文已有的连接词。** 英文用分号或并列句表达因果，中文加"因此""而"是为了可读性。

> 源：Capital accumulates; the reserve army grows.
> 译：资本积累起来，产业后备军也随之扩大。
> （"随之"点出原文分号已含的伴随关系，可以。）

**拆长句。** 一句英文拆成两句中文，只要不增不减信息。

> 源：Because the labour process is subsumed under capital, the worker confronts the product as an alien power, a power that grows with accumulation.
> 译：由于劳动过程被纳入资本之下，工人面对的产品成为一种异己的力量。这种力量随着积累而增长。

**合短句。** 几句英文并作一句中文，同样不增不减。英文爱用短句串联（尤其 `It does X. It also does Y.`），中文照抄会显得断续；并成一句，逻辑关系反而更清。

> 源：Money capital is set free. This happens periodically. The amount depends on the turnover period.
> 译：货币资本会周期性地游离出来，游离的量取决于周转期间的长短。

### 禁止的

**补原文没有的事实或背景。**

> 源：Sraffa published *Production of Commodities* in 1960.
> ✗ 译：斯拉法在1960年出版了《用商品生产商品》，此书后来成为新李嘉图主义的奠基之作。
> （后半句原文没有。要补充就写进报告，不进正文。）

**替作者下判断、加评价。**

> 源：The evidence is mixed.
> ✗ 译：证据莫衷一是，说明该理论难以成立。
> ✓ 译：证据并不一致。

**合并段落。** 英文里相邻两段各说一层，中文看着"可以并"，但并了就破坏一一对应。

> 源：（段 A：定义剩余价值）（段 B：说明剩余价值率的计算）
> ✗ 译：（合成一段，中间用"具体而言"连接）
> （对账脚本会立刻报块级结构不一致。）

**拆段落。** 同理，一段拆两段也不行。段内可以用分号、句号、破折号调节节奏。

**省略"重复"的句子。** 学术写作里的回指句（`As noted above, ...`）是有功能的，删了读者会失去锚点。

**把脚注内容并进正文，或把正文移到脚注。** 位置是结构的一部分。

### 灰色地带

**连接词。** 原文无连接词、中文必须加一个才通顺时，加"而""则""就"这类**语义中性**的连接词可以；加"因此""所以""由此可见"这类**声称因果**的不行，除非原文确有因果。

**术语的括注。** 首次出现加原文括注（`劳动过程（labour process）`）是学界惯例，算作排版而非增补。但只在首次，且不能每段都加。

**YAML front matter。** 译文顶部的元信息块（标题、作者、年份、DOI、术语表路径、校验统计）不算增补。它是文件属性，不是正文：标准 Markdown 渲染不显示，所有对账脚本先剥掉它再比对。

边界很窄，越过就是增：

| 可以放 | 不能放 |
|---|---|
| 书目信息（title/authors/year/journal/doi） | 内容摘要、章节提要 |
| 过程记录（translated_at、glossary、terms_used） | 译者的理解、评论、按语 |
| 机器校验结果（块数、引用数、status） | 术语对照表、译名说明 |

术语对照表这类东西单独存成 `_work/` 下的文件。塞进 front matter 会让它在某些工具里被渲染成正文，等于把"译者补的内容"混进译作。

## 规则 2：保留 Markdown 结构

### 必须逐字保留的

| 元素 | 要求 |
|---|---|
| `#` ~ `######` | 层数与顺序不变；标题文字译 |
| `-` `*` `+` 列表 | 符号可统一成 `-`，但**数量与嵌套层级不变** |
| `1.` `2.` 有序列表 | 编号连续，不重排 |
| `>` 引用块 | 层级（`>>`）不变 |
| `\|` 表格 | 列数、行数不变；分隔行 `\|---\|` 保留 |
| `![alt](path)` | 路径一字不改；`alt` 可译 |
| `[text](url)` | `url` 不改；`text` 可译 |
| `[^1]` 脚注 | 标记不改；脚注正文译 |
| ` ``` ` 代码块 | 整块不动，包括语言标记 |
| `**` `*` `~~` `` ` `` | 位置与配对不变 |

### 常见破坏方式

**加粗范围漂移。** 英文 `**the law of the tendency of the rate of profit to fall**` 中文若写成 `**利润率趋向下降的规律**`，字号对应即可；但不要只加粗其中几个字，也不要把整个句子加粗。

**列表符号改成中文标点。** `- 第一点` 不能写成 `· 第一点` 或 `、第一点`。

**表格塌成纯文本。** 提取阶段常见，译之前就要修好，不要在译文里把表格写成"第一列是……第二列是……"。

**图片路径被"本地化"。** `![](images/fig1.png)` 改成 `![](图片/图1.png)` 图就断了。

**在公式块内部加中文。** `$$ ... \text{其中} ... $$` 里的 `\text{}` 若原文是英文，保留英文；不要在公式里插中文解释。

## 规则 3：信达雅，但不许越界

规则 1 与规则 3 的张力是这份工作的核心。判据只有一条：**改写后信息量完全等价**。等价就润色，不等价就退回直译。

下面列的是常见的病，不是必须套用的句式。**没有一种句法比另一种更"忠"**——句序、断句、主从、语序，都是译者按上下文该拿主意的地方；同一位作者的不同段落，也需要不同的处理。列出来只为让人认出"这是英语留下的痕迹"，认出之后怎么改，由译者定。

### 该润色的地方

**名词化 → 动词化。**

> ✗ 资本对劳动过程的**控制的实施**依赖于……
> ✓ 资本**实施**对劳动过程的控制，依赖……

**被动 → 主动（当施动者明确时）。**

> ✗ 剩余价值**被**工人**所**生产。
> ✓ 工人生产剩余价值。

**"进行/作出/加以 + 名词" → 动词。**

> ✗ 对利润率**进行**了下调**的**分析。
> ✓ 分析了利润率的下降。

**成串的"的"。**

> ✗ 资本的有机构成的提高的后果的严重性
> ✓ 资本有机构成提高带来的严重后果

**英文语序照搬。**

> ✗ 这是一个不仅在经济上而且在政治上具有重要意义的变化。
> ✓ 这一变化不仅在经济上重要，在政治上同样重要。

**代词还原。** 英文学术写作大量用 `it` `this` `the latter`，中文照译会指代不清。在可能歧义处换成具体名词。

**头重脚轻的主语。** 英文惯于把一长串定语挂在主语前，中文照搬会让读者等到句末才知道在说什么。遇到"被 X 称作……的 Y，提供了……"这类结构，先把来源交代清楚，再让 Y 自己起一句。

> ✗ 被曼德尔在他 1978 年为第二卷所写的导言中称作"被遗忘的"第二卷，提供了一个出人意料的视角。
> ✓ 曼德尔在 1978 年为第二卷所写的导言里，把这一卷称作"被遗忘的"一卷。其实它提供了一个出人意料的视角。

**系表结构套虚动词。** `resists formalization by conventional methods` 直译成"是抵制用常规方法加以形式化的"，中文里没有这种说法。

> ✗ 这一理论是抵制用常规方法加以形式化的。
> ✓ 这个理论用常规方法无法形式化。

**状语全堆在句末。** 英文可以把"在……条件下""就……而言"一路后缀下去，中文读到第三个介词短语就断了。

> ✗ 分析在给定各个资本主义企业假设数据的条件下三种资本形式的总量波动。
> ✓ 以假设的单个资本主义企业数据为输入，考察三种资本形式在总量上的波动。

**句读随义，不随原句。** 句子在哪儿断、哪几句并作一句，看中文的论述单位，不看英文的句号。英文的长句要拆，英文的散句要合，两者都不是"改写"，是让同一串信息在中文里找到它该有的骨架。

拆的理由只有一个：原句在中文里承载不了——主句被两三个从句压住，读到句末已经忘了主语。

> 源：Marx provides there the foundation for a theory of macroeconomic fluctuations that resists formalization by conventional methods.
> ✗ 马克思在那里为一个无法用常规方法形式化的宏观经济波动理论打下了基础。
> ✓ 马克思在那里为一个宏观经济波动理论打下了基础。这个理论用常规方法无法形式化。

合的理由同样只有一个：几个分句说的是同一个论断的不同侧面，切开就割断了推理，读起来像清单。

> 源：The process is continuous. Its continuity derives from the production process. That process does not stop. Hence money must constantly flow back.
> ✗ 这一过程是连续的。它的连续性来自生产过程。生产过程本身不中断。因此货币必须不断流回。
> ✓ 这一过程之所以连续，是因为生产过程本身不中断；也正因如此，货币必须不断流回。

判断的单位是**一段话里有几个论断、论断之间是什么关系**，不是原文有几个句号。一段里连着四五句都只有十来个字、每句换一个主语，是把该合的拆了；一句话里套了三个"的"、读到后半句要找主语，是把该拆的没拆。**不要为整齐而拆，也不要为紧凑而合。**

**评语别嵌在动宾之间。** 英文的 `surprisingly`、`importantly`、`in effect` 可以插在句中，中文若原位照译，主干会被截断。或前置、或另起短句，看哪样读着顺，不必一律后置。

> 源：The second volume offers, surprisingly, a fairly fresh perspective.
> ✗ 第二卷提供了，出乎意料地，一个相当新鲜的视角。
> ✓ 第二卷提供的视角相当新鲜，这一点出人意料。
> ✓ 出乎意料的是，第二卷提供了一个相当新鲜的视角。

**按中文配价重铸动词。** 英文的介词框架不能整块搬过来。`refer to A as B` 是"把 A 称作 B"，不是"指称 A 作为 B"；`subject A to B` 是"使 A 受 B"，不是"使 A 服从于 B"。动词定了，宾语和补语的位置跟着变。

**并列项要对得起来。** `A, B, and C` 若一项六字、一项两字、一项十字，读起来是散的。让三项词性一致、结构一致；字数不必强求相等，但不宜悬殊。原文三项本来就不齐（一个是概念、一个是一整个从句），照实译出，不要为了齐整把从句压成一个词——那是增删。

**自查办法**：译完一段，遮住英文只读中文，找三种症状——必须回看原文才懂的，是没译完；一口气读不完、要停下来找主语的，是该拆没拆；连着几句都十来个字、句句换主语、读着像条目清单的，是该合没合。

**这一段怎么断句，由译者按上下文定。** 语序、主从、停顿、评议的位置、并列项的字数，都不必与英文对应；同一段话，改三次断法可能三次都通。这不是"自由发挥"的余地，而是译者的职责——只要不跨段合并、不动列表表格公式的结构，句子层面的处置权在这一步完全属于译者。

### 语体：学术书面语，宁略生硬，不可口语

读者是研究者，载体是论文。文中不能出现随笔腔、讲课腔、聊天腔。**判断很简单：这句话能不能出现在《资本论》中译本的注释里？不能，就改。**

> ✗ 这些假设要记的东西不少，其中好几条还得再说几句。
> ✓ 这些假设涉及的事项确实繁多，其中若干条尚须进一步说明。

> ✗ 这样一章在马克思主义文献里讨论得却相当少，不免令人意外。
> ✓ 这一章在马克思主义文献中讨论甚少，不免令人意外。

> ✗ 有了周转连续体这个直观的辅助，马克思的文字讨论好懂得多。
> ✓ 借助周转连续体这一直观辅助，马克思的文字讨论远为易解。

三类病：

| 层 | 症状 | 改法 |
|---|---|---|
| 词 | `东西` `玩意儿` `大把` `满手` `运气` `赚` `钱` `搞` `弄` `折腾` `啥` `咱` | 换成对应的书面词：`事项` `大量` `充斥着` `资金` `厘清` `处理` |
| 句 | `要……的东西不少` `还得说几句` `好懂得多` `看得清` `不容易` `没什么两样` | 换成`涉及的事项繁多` `尚须说明` `远为易解` `可以看清` `亦无不同` |
| 语气 | 调侃、感叹、反问、亲切的插入语（`别忘了` `说白了` `不妨` `所幸` `好在`） | 一律删去或改为中性陈述。学术文本不需要与读者套近乎 |

**边界：书面不等于文言。** `故` `此` `该` `尚须` `当推` 可以用，但不要通篇`……者也`；更不要为了文雅牺牲准确——`故` 不能替代因果关系的具体说明，`该` 不能替代限定词。**宁可略生硬，也不要为了顺口而口语化**；但生硬不等于病句，"是……加以……的"这类照搬英文的框架仍要改（见上文）。

**译完全篇自查一次**：`python scripts/style_check.py <stem>_zh.md`，它按词表扫出可疑句，逐句看是改还是放行。

### 不许动的

**限定词。** 这是政治经济学翻译最容易出事的地方。

| 英文 | 必须保住的意思 | 常被错译成 |
|---|---|---|
| `tends to` | 只是一种趋势，可被抵消 | 会、必然 |
| `tendentially` | 同上，且是理论层面的趋势 | 实际上 |
| `in the long run` | 长期，非当下 | 最终、从根本上 |
| `only` / `merely` | 排他或贬低 | 常常被吞掉 |
| `as such` | 就其本身而言 | 因此 |
| `not necessarily` | 未必 | 不会 |
| `may` / `can` | 可能 / 能够（不同） | 混用 |
| `presupposes` | 以…为前提 | 意味着 |
| `determines` vs `conditions` | 决定 / 制约（马克思主义文献里严格区分） | 都译"决定" |

`determines` 与 `conditions` 的区分在阿尔都塞传统里是核心，译混了整段论证就变形。遇到这类词先查该文所属传统，再定。

**否定范围。**

> `Not all capitalists benefit.` ≠ 所有资本家都不受益。 = 并非所有资本家都受益。
> `Few studies address this.` ≠ 一些研究涉及。 = 很少有研究涉及。

**因果连词不能凭空加。** 原文只是时间先后，中文不能写成"因此"。

## 规则 4：文献引用保持原样

### 处理矩阵

| 形态 | 例子 | 处理 |
|---|---|---|
| 括号作者—年份 | `(Shaikh, 2016, p. 42)` | **逐字保留**，含 `p. 42` |
| 多篇并列 | `(Marx, 1867; Sraffa, 1960)` | 逐字保留，分号与顺序不变 |
| 方括号首版年 | `(Marx [1867] 1976: 173–6)`、`(Marx, 1987a [1872]: 90)` | 逐字保留，**含方括号里那个年份**；冒号位置不动，不因为"年份后面该接冒号"就改写 |
| 叙述式 | `Marx (1867) argued that...` | 括号部分保留；`Marx` 按人名规则处理 |
| 数字引用 | `[12]`、`[12–15]` | 逐字保留 |
| 同上 | `ibid.`、`op. cit.`、`idem` | 逐字保留 |
| 脚注引用 | `[^3]` | 标记保留，脚注正文译 |
| 参考文献条目 | `Shaikh, A. (2016). *Capitalism*. Oxford: OUP.` | **整条原样**，不译作者、书名、出版社，不改标点顺序 |
| 正文提到的书名 | `*Production of Commodities by Means of Commodities*` | 保留原文，斜体保留 |
| 引文（直接引用） | `"the hidden abode of production"` | 保留原文；如需译文，放在引文后的括号内并标明"译者译"，但更稳妥是不译 |
| 页码 | `p. 163`、`pp. 12–18` | 原样；**不换成译本页码** |

**参考文献表整块不进翻译上下文。** 上表最后几行说的是字面意思：一份书目由 `scripts/split_refs.py` 从翻译用稿里切走，原文著录一字不改地贴回，模型根本没有机会碰它。所以要守住两件事——翻译时不要去找那行标记之外的书目内容（它不在文件里），拼回时不要顺手"统一一下格式"。条目的标点、姓序、斜体、破折号都是原文的一部分，看着不合中文习惯也照留。

**方括号里的首版年不是冗余。** 它把「版刻年」与「作品」分开：`(Marx, 1987a [1872]: 90)` 说的是「MEGA 1987 年出的那一卷里、原刊 1872 年的那部作品、第 90 页」。删掉 `[1872]`，读者就分不清引的是《资本论》第一卷还是别的东西——MEGA 一个年份往往对应好几部手稿。所以照抄，顺序与冒号位置都不动。锚定卷次时真正管用的也是它，见 [marx-ref.md](marx-ref.md)「引用串的四种写法」。

### 学者姓名：句中留中文，括号附原名

分两种，判据是**这个名字在句子里有没有职务**。

**一、姓名是句子成分**（主语、宾语、定语、"用……的话说"这类），中文名照常译出，括号里给英文原名、年份、页码：

> 源：Campbell (1998: 140) refers to this tendency as "the microeconomic function of circulation hoards."
> ✓ 译：坎贝尔（Campbell, 1998: 140）把这种倾向称作"流通贮藏的微观经济功能"。

> 源：In Dymski's (1990: 43) terms, ...
> ✓ 译：用迪姆斯基（Dymski, 1990: 43）的话说，……

> 源：Both Engels in volume 3 of Capital (1981: 163) and Mandel (1968: 188) acknowledge ...
> ✓ 译：恩格斯在《资本论》第三卷（Engels, 1981: 163）和曼德尔（Mandel, 1968: 188）都承认……

**二、姓名不进句子**，只是给这句话标出处，用纯括号：

> ✓ 译：……这种"潜在的货币资本就是信用制度的资金来源"（Campbell, 1998: 149–51）。

**括号用中文括号「（）」，年份页码用半角冒号。** 全角括号是中文排版，与正文一致；`1998: 140` 里的冒号跟外文习惯，不换成全角。

**引号也用中文引号「“”」「‘’」。** 英文原文的 `"..."`、`'...'` 一律转换；引文里再套引文用单引号，即 `“……‘……’……”`。英文所有格撇号（`Dymski's`）不是引号，不转。整篇转换交给 `scripts/zh_quotes.py`，它跳过 front matter、参考文献、公式与代码；参考文献是原文，按规则 4 保持英文标点。

**马克思、恩格斯也一样标作者。** 正文说"马克思"，标注就写 `（Marx, 1978: 357）`；恩格斯的编者注写 `（Engels, 1978: 359–60）`。**作者看引的是谁的话，不看文章标题**——同一篇里既引马克思也引恩格斯，混着标 `（1978: 360）` 会让读者无法分辨哪句是马克思、哪句是恩格斯的插入。

### 不许做的

- 把 `(Shaikh, 2016)` 改写成 `（谢赫，2016）`——括号里的姓是被引用的标识，不是正文。
- 把 `(Marx, 1987a [1872]: 90)` 简写成 `（Marx, 1987: 90）`——首版年是作品标识，不是可省的冗余；冒号也不许搬到年份后面。
- 漏掉英文引文的单引号 `‘…’`，或把它当成所有格撇号略过——英式排版的引号是 `‘…’` 而不是 `"…"`，整句没译时照抄，整句译了按规则 4 换中文引号。
- 把 `Campbell (1998)` 写成 `坎贝尔（1998）`——括号里没有英文原名，读者没法对参考文献。
- 把 `Campbell (1998)` 写成 `坎贝尔（Campbell (1998)）` 这种括号套括号。
- 把参考文献表按中文习惯重排、补上译者、把出版社译成中文。
- 把 `et al.` 译成"等"。
- 把英文引文的引号改成中文引号（除非整句已译）。
- 给引用加"参见""详见"等中文引导语，而原文没有。

## 规则 5：公式定界符

### 目标形态

| 源 | 目标 |
|---|---|
| `\[ x^2 \]` | `$$ x^2 $$`（独立成行时用 `$$\n x^2 \n$$`） |
| `\( x^2 \)` | `$x^2$` |
| `$$ x^2 $$` | 不变 |
| `$x^2$` | 不变 |

### 细则

**多行公式整块保留。** `\begin{aligned}` `\begin{align*}` `\begin{cases}` `\begin{array}` 内部一个字符都不动，只处理外层定界符。

**公式编号用 `\tag{}`。** `\begin{equation}...\end{equation}` 若出现在 Markdown 里，转成 `$$\n... \tag{3}\n$$`，原编号照抄，不重排。

**单位与文字。** `\text{Labour}` 里的英文保留；货币符号、百分号、单位照原样。

**上下标与函数名不许"美化"。** `\mathrm{d}x` 不要改成 `dx`；`\operatorname{sign}` 不要改成 `sign`。

**`\\[2pt]` 是换行间距，不是定界符。** 矩阵、`aligned` 里常见 `a \\[2pt] b`，脚本已用"前一个字符不是反斜杠"的规则避开，手工改的时候也要注意。

**不要为了排版把行内公式改成行间。** 源文行内的 `$O(n)$` 保持行内。

### 用脚本，不用手

```bash
python scripts/normalize_math.py paper_zh.md --inplace
```

脚本跳过代码块、行内代码、已有 `$$` 区域，并可重复运行。手工改容易在 `\\[` 上出事，且不可复现。

## 规则 6：成品只留正文

刊物的版头版尾不是文章的一部分。它们要么已经进了译文顶部的 YAML 元信息，要么本来就不必给读者看。**成品译文里不留这些块：**

| 块 | 处置 |
|---|---|
| 标题（H1） | 删。`title` / `title_zh` 在 front matter 里 |
| 作者、单位、通讯地址、电子邮箱 | 删。`authors` 在 front matter 里 |
| 收稿日期、接受日期 | 删。`received` / `accepted` 在 front matter 里 |
| JEL 分类号、关键词 | 删。`keywords` 在 front matter 里 |
| 文末作者简介（"×××自某年起任……"） | 删 |
| 基金资助、致谢 | 删（致谢若含学术性说明，可移进 `notes`） |
| 摘要 | **保留**。它是正文的一部分，不是版头 |

**源文件要同步删。** `fidelity_check.py` 按块序列对账，译文删了、源文件没删，会立刻报"块级结构不一致"。正确做法是在源文件的整理脚本（如 `fix_source.py`）里加一段过滤，而不是只改译文——否则下次重装配，删掉的块又会回来。

**注意 `re.sub` 的换行。** 删整块时把结尾的 `\n\n` 一并吃掉，会让下一块粘到前一块上（脚注尤其容易中招）。用 `\n*` 收尾后至少补回一个空行，删完再 `re.sub(r"\n{3,}", "\n\n", md)` 清一遍。
