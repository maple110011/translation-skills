# 默认风格约定（总表）

所有篇目的起点。开新篇时复制一份到 `_work/<stem>_风格.md`，只改本篇要变的项——别每篇从空白重写，那等于每篇重新决定一次，正是风格漂移的来源。

这份总表的来源：28 篇已译中文稿的实测统计（2026-11 统计，`译介存档/` 与 `周转理论三篇译介/` 中 5000 字以上的译稿）。有数据支撑的项标了依据；没数据的写"建议"，是通行做法而非你的习惯，第一次用它时留意一下。

## 怎么增补

某一条在**连续两三篇**里都被你改成了同一个新值，那是偏好变了，回来改总表。只在一篇里改的，写在那一篇的项目文件里，不要上抬——单篇的特例上抬成通则，下一篇会被莫名其妙地约束。

## 自称

- 作者指自己：**我们**（实测 777 次；"本文" 235、"文章" 44、"笔者" 7）
- 原文 `we`（作者复数）：译"我们"，不转成"本文"
- 原文 `we`（泛指，含读者）：**建议**译"我们"或改无主句，不译"人们"
- 原文 `one`：**建议**省去主语改主动，或译"人们"
- `the author`／`this paper`：译"本文"

> 判据：这一项最容易被"更学术"的直觉带偏。你的实际译稿里"我们"压倒性占多数，说明你不回避第一人称——别在某一篇里突然全改成"本文"。

## 论证动词（全篇一致，跨篇也尽量一致）

| 原文 | 默认 | 备注 |
|---|---|---|
| argue | 论证 | 带论证过程时；单纯表态可用"主张" |
| claim | 主张 | 比 argue 弱，作者常带保留 |
| claim that（作者不同意时） | 声称 | 拉开距离的信号，别抹平 |
| suggest | 表明 | 也可"提示"，但一篇内只选一个 |
| show | 表明 | |
| demonstrate | 论证 | 比 show 重 |
| contend | 主张 | |
| maintain | 坚持认为 | 强调对方立场未变 |
| note／observe | 指出 | |
| point out | 指出 | |

> 这一组是**建议值**，未做平行语料统计。第一次用某篇稿子校一遍：如果一篇里 argue 一处"论证"一处"主张"，就是没定死。

## 句式

- 基调：**偏书面长句，保留从句层次**（建议）——政经文献的限定条件常挂在从句里，拆太碎会丢掉限定关系
- 英文插入语与破折号：破折号保留，成对出现时不要改成括号
- 段落内节奏：跟随原文的论证推进，不按中文习惯重排段落
- 冒号引出解释：保留（政经文献常用）

## 数字与体例

- 百分比：**`%`**（实测 58 次，`百分之` 0 次）
- 数字区间：**短横 `–`**（实测 169 次 vs 连字符 94 次，尚未统一——以此为准定死）
- 页码：`p. 163`、`pp. 12–18`，与引文规则一致
- 年代：`1970 年代`，不用 `1970s`
- 千分位与小数：`1,234`、`0.5`，不改成中文数字
- 变量：行内 `$x$`，正文提及变量保留斜体意义

## 引文与页码

- 括号引用：全角括号、半角冒号，`（Marx, 1976: 163）`（规则 4）
- 引号：**中文弯引号 `“”`**（实测 1939 次，`「」` 0 次）；嵌套用 `“……‘……’……”`
- 直接引语：整句译出，引号内用中文；页码原样保留不换成译本页码
- 译者注：不写，进交付报告（本 skill 默认）

## 禁用

- 口语与随笔腔：<玩意儿／大把／说白了／所幸／别忘了／搞／弄／折腾>
- 翻译腔：<对……进行……／是……加以……的／连续"被"字句／关于……方面>
- 空洞连接：<值得注意的是／综上所述／由此可见／不难看出>
- 程度空话：<极大地／在很大程度上／在一定程度上>（原文没有就不加）

> 这一节会被 `style_check.py --style` 读取，词与句式都查。句式用省略号写（`对……进行……`），脚本会当通配处理。
