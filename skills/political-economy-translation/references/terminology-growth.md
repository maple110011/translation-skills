# 核心术语表怎么积累

先说一个反直觉的判断：**术语表不是"收集"出来的，是"被正在译的东西逼出来"的。**

现有那份专名表就是反例。它是翻译工具在逐篇处理时顺手抓的，抓的是人名地名，不是概念。三年攒下 5404 条，其中 4234 条只在一篇文献里出现过——按参考文献不译的规则，这些条目一次都用不上。裁剪后剩 1170 条，但"剩余价值"依然不在里面，因为它从没被当目标找过。

核心术语表要有目标：**让下一篇译文不必重新决定同一个词。**

---

## 一、三层结构，别做一张大表

| 层 | 规模 | 内容 | 稳定性 |
|---|---|---|---|
| 核心层 | 100–200 条 | 全领域通用：价值、剩余价值、劳动力、资本有机构成、利润率趋向下降 | 高，几年不变 |
| 分支层 | 每支 30–50 条 | 劳动过程、金融化、世界体系、斯拉法体系、技术社会学 | 中，随分支文献增长 |
| 项目层 | 每篇 20–40 条 | 只在这一篇里有意义的具体译法 | 低，随文归档 |

现在的 `core_terms_draft.csv`（134 条）是核心层草案。分支层几乎是空的——这是下一步真正要补的地方，而不是继续往核心层堆。

**为什么不能做一张大表**：不同分支的同一个词会打架。`regulation` 在调节学派里是"调节"，在劳动过程里可能是"规制"，在金融监管语境里是"监管"。一张表放不下三种约定，只能分层并标注适用域。

---

## 二、收录门槛

不是所有词都值得进表。只收**译错会改变论证**的词：

- 影响因果方向的：`determines` / `conditions`（决定 / 制约）
- 影响数量关系的：`rate of surplus value`（剩余价值率，不是"剩余价值比率"）
- 影响层级结构的：`department I`（第 I 部类，不是"部门一"）
- 有学派标记功能的：`surplus approach`（剩余方法/剩余进路，选一个就意味着站队）

不收：普通形容词、通用动词、只出现一次的描述性短语。它们进表只会稀释信噪比。

**入库门槛**：同一译法在 ≥2 篇独立文献中出现，或被经典译本/权威辞书支持。只在一篇里出现过的，留在项目层，不要急着升格。

---

## 三、每条必须有"依据"

表的可用性取决于能否复核。三个月后你不会记得当初为什么选"剩余方法"而不是"剩余进路"。

```csv
src,dst,alt,confidence,topic,status
surplus approach,剩余方法,剩余进路,medium,方法论,待校对
```

`alt` 记备选，`confidence` 记把握，将来再加一列 `basis` 写依据（"《用商品生产商品》商务印书馆译本导言"、"《政治经济学评论》2021 年第 3 期惯用"）。没有依据的条目，等于把决定留给下一个翻到它的人。

---

## 四、具体动作

### 每篇译完的十分钟

1. 把这篇临时定的译法从工作记忆里倒进 `_work/<篇名>_术语.csv`（20–40 条）。
2. 跑一次全量合并，看新增冲突：

```bash
python scripts/merge_glossary.py ./政经术语表整理 -o ./政经术语表整理/_整理结果
```

3. 只看报告里"待裁决"那一栏涨了多少。涨得多，说明这个分支的译法还没收敛，该停下来定一次内部标准，而不是继续逐篇临时决定。
4. 每隔十篇跑一次裁剪，把只出现过一次的条目赶进档案：

```bash
python scripts/prune_glossary.py ./政经术语表整理/_整理结果/glossary_master.csv \
    -o ./政经术语表整理/_整理结果 --min-files 2
```

表越长越难查，查不动就没人查，没人查的表等于不存在。

### 抽取候选词的四条触发线

不用通读找词，只盯这四个信号（`extract_terms.py` 已把它们都实现，`signals` 列直接标出）：

1. **重复**：同一名词短语出现 ≥3 次。
2. **强调**：原文用斜体、引号、破折号包起来的词（作者在提示这是术语）。
3. **构词**：`-ism`（学派）、`-ization`（过程）、`-ation`（过程）、`-de` 前缀（去…化）。
4. **结构**：`the X of Y`（`the law of the tendency of...`、`the organic composition of...`）——这类几乎全是术语。

自动化了这一层，剩下的判断才值得花时间：哪个短语是术语、哪个只是碰巧重复的普通搭配。

### 查证顺序

1. 本文所属传统的经典译本（马克思主义 → 《资本论》人民出版社版；斯拉法 → 《用商品生产商品》商务印书馆版）
2. 近五年中文核心期刊的用法（《政治经济学评论》《马克思主义与现实》《国外理论动态》）
3. 相邻学科的既有译法
4. 构词法直译 + 首次括注原文

前三条都没有，才轮到自己定。自己定的，`confidence` 标 `medium`。

## 五、四个已经踩过的坑

**贪多。** 一次收 500 条，90% 再也不会用到，维护成本超过收益。表的价值等于"被查过的次数"，不是条目数。

**混角色。** 把专名和概念放一张表。`price` 作为概念是"价格"，作为人名是"普赖斯"——现有累积表里就有一条 `price → 普赖斯`。查表必须先看 `kind`。

**跨项目套用。** A 书定"剩余价值额"，B 书定"剩余价值量"，都有道理。术语表是项目级的，总表只是候选池。

**只增不删。** 定错了不敢改，于是一个错译法靠频次越滚越"权威"。正确做法是改 `dst`、把旧值移到 `alt` 并注明"已废"，保留痕迹而不是保留错误。

---

## 六、优先级建议

如果只有半天：

1. **先过 134 条核心术语**（2 小时）。它覆盖政经文献 70% 的概念密度，投入产出比最高。逐条看 `dst` 和 `alt`，把 `status` 改成"已定"，删掉不同意的备选。
2. **再按你实际在译的专题补一支分支层**（2 小时）。哪个专题手头在译就补哪个，别按学科完备性补。
3. **最后处理 192 条待裁决专名**（1 小时）。只看前 50 条高频的，后 140 条出现一两次，选哪个几乎不影响读者。

不要做的事：试图一次建齐所有分支；试图给所有生僻人名定音译；试图让表"完备"。

---

## 七、一个实用技巧：给源词加传统标记

同一个英文词在不同传统里译法不同，这靠"一个 src 一个 dst"解决不了。做法是在 `src` 后加方括号标注适用域：

```csv
value [Marxist],价值
value [Sraffian],价值
determines [Althusserian],决定
conditions [Althusserian],制约
regulation [Régulation],调节
regulation [labour process],规制
```

查表时按当前文献的传统取对应行。这比维护多张表简单，也不会混淆。
