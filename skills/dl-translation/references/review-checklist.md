# 交付前清单

分两段看：第一段是脚本已经查过的，只需读结论；第二段是脚本查不到、只能靠人读的。**脚本通过不等于译文合格**，它只是把机械错误挡在人读之前。

---

## 一、脚本查过的：读结论，不用重查

| 脚本 | 查什么 | 失败怎么办 |
|---|---|---|
| `fidelity_check.py --float-reflow` | **正文**块级结构一一对应、标题层级、列表项、引用块、引用是否原样、定理类环境条数；浮动对象按多重集合核对图片路径／图注编号／表行数；`keep` 术语反向检查 | 硬性失败必须清零；忘了 `--float-reflow` 会把"图表搬位置"误报成结构不一致 |
| `math_fidelity.py` | 公式数量、逐字一致、`\tag` 序列、`\label`/`\ref`、`$` 是否成对 | 一处都不能留；"微差"最常见是上下标或不等号 |
| `figures.py relocate` + `audit` | 每个浮动对象是否紧跟首次引用段落、图注数、图号连续性、图注是否紧跟图、正文引用是否有对应图注、图片文件是否存在、alt 是否为空 | 图注数与原文不一致要查是漏译还是被并进图片；"未就近"要跑 `relocate --apply`；无引用的块写进交付报告 |
| `notation.py check` | 正文符号是否都进了表、表里是否有正文用不到的符号、格子是否包 `$` | 缺失项按频次判断；多余项逐个核对（多为抄错） |
| `review_queue.py` | 术语不一致、候选术语、公式/符号待定项 | 术语不一致默认照表改 |
| `footnote_recover.py --check` | `content_list.json` 里的 `page_footnote` 是否全部补进 `## 脚注` 节（`full.md` 会整类丢脚注） | 返回 1 就是有脚注没补，先补再交付 |
| `fidelity_check.py --strict`（脚注门禁） | `_work/脚注.csv` 存在、译文有 `## 脚注` 节、`[^n]:` 定义数 ≥ 清单内容脚注条数 | 硬性失败；只有纯 Markdown 输入可显式 `--skip-footnote-check` 并写明理由 |
| `md2tex.py --pdf` 后的文本层 | `pdftotext` 搜脚注里的关键词，确认脚注真的进了 PDF（编译 0 错误不代表内容在） | 搜不到就查 `## 脚注` 节是否被渲染 |

这些结论要写进交付说明，不要只说"校验通过"。**脚注这一项不可跳过**：MinerU 静默丢整类 `page_footnote`，编译不会报错，只有脚本门禁能挡住。

## 二、必须人读的

### A 公式的语义（不是字符）

字符一致不代表指代一致。逐条看：

- [ ] 每个符号指的东西，与符号表、与正文第一次定义它的那句话，是同一个东西吗？
- [ ] 上下标的语义对吗（$x_i^{(t)}$：个体 / 迭代；$W^{(l)}$：层号）？
- [ ] 求和、积分、乘积的上下限对得上正文（$\sum_{i=1}^{n}$ 与"$n$ 个样本"）？
- [ ] 公式里的索引在正文里有没有对应（$j=1,\dots,K$ 的 $K$ 在哪定义）？
- [ ] 文字与公式对得上吗——"第一项趋于零"指的是哪一项，译文读者能不能认出来？
- [ ] 公式之间的推演顺序（(3) 由 (2) 代入得到）有没有被译乱？
- [ ] `\text{…}` 里的标签译了没有？一篇之内是否统一（全译或全留）？

### B 定理类陈述

- [ ] 每条定理/引理/命题的条件，逐条对照 `accuracy-rules.md` §2.3 那张表：范围、正则性、概率模式、依赖关系、一致性，一样没少？
- [ ] 结论强度没被抬高或压低（上界 vs 下界、"至多相差常数" vs "相等"、"存在" vs "任意"）？
- [ ] `if` / `only if` / `iff` 三档没混？
- [ ] 证明里 `without loss of generality`、`by symmetry`、`by induction`、`by contradiction` 都在？
- [ ] 内部引用（`by Lemma 2.3`、`by (4)`）的编号与译文实际编号一致？
- [ ] 定义写成了定义的口吻，没写成定理（"称 $X$ 为……，若……"）？
- [ ] 脚注里的条件译了吗（脚注常藏假设）？
- [ ] `_work/脚注.csv` 里每条 `footnote` 都在译文 `## 脚注` 节有对应中文，页码、编号、URL 一字不差？`pdftotext` 能在 PDF 里搜到脚注关键词？

### C 数值、表格、算法

- [ ] 表里的数字、星号、括号里的标准误、单位，一个都没动？
- [ ] 表注说清了 ± 是标准差还是标准误？
- [ ] 有效数字与量级没被"简化"（$10^{-3}$ 没变成 0.001，$2.5\times10^4$ 没变成 25000）？
- [ ] 区间开闭、$\le$ 与 $<$、$\approx$ 与 $=$ 各自保留？
- [ ] 伪代码的步号、循环结构、函数名、超参数取值没动？

### D 图与表的位置与版式

- [ ] 每个图／表块都紧跟在**正文首次引用它的段落之后**（对照 `_work/图表重定位.csv`）？没有引用的块已在交付报告里列出？
- [ ] 搬动只改了位置：图片路径、图注文字与编号、表注、表格行列数值、正文段落顺序都没变？
- [ ] 每条图注紧跟在自己的图块后面，中间没有正文段落？
- [ ] 一张图注对应一个图块——没有两个图注共用一个块，也没有一个图注对应四个散块？
- [ ] 多面板图是整张图或一个并排图块，没有竖排摞在一起？并排图块有 `figure:start/end` 标记？
- [ ] 原文是四条独立图注的，没有被合成一个块？
- [ ] 译文里每个"图 N"都能找到图注，每个图注都被正文引用过？
- [ ] 宽图缩到正文宽度后，图里的刻度和图例还读得出来？（脚本判不了，只能看）
- [ ] 多级表头用 HTML 表格，数字列右对齐，表注在表下方？
- [ ] 子图说明：原文是文字的都译了，烧在位图里的没有凭印象补写？

### E 术语与符号一致

- [ ] `kind=keep` 的术语全文保留英文、逐字符一致（大小写／单复数／连字符／缩写），没有在某处冒出自造中文译名？
- [ ] 「保留英文术语一览」里的英文串与正文逐字符一致，中文简述没有带进原文没有的信息？
- [ ] 有通行译名的通用术语照译了，没有把整篇都留成英文（"保留"是裁定，不是偷懒）？
- [ ] 术语表里定的词，全文都照用了（不是只在前面几页照用）？
- [ ] 同一个英文词在不同节没被译成两个中文词（`consistency` 相合性/一致性混用是最常见的）？
- [ ] 缩写首现给了全称，之后统一？
- [ ] 符号表"含义"列里的中文词，与术语表写法一致？
- [ ] 原文有 Notation 节时，该节译法与开头符号表一致？

### F 中文可读性（最低限度，不做润色）

- [ ] 句子能读通：主谓宾齐全、指代明确、没有成串的"的"？
- [ ] 术语在同一句内不打架（同句出现两个中文名指同一个东西）？
- [ ] 标点用中文标点（公式、代码、参考文献里的符号除外）？
- [ ] 没有为了顺口而增删的过渡句、解释句、连接词？

### G 原文疑点

- [ ] 符号前后不一致、假设与证明对不上、编号跳号、公式疑似漏下标——都记进报告了吗（**没有替作者改**）？
- [ ] 提取错误（上下标压平、`O(n)` 误识为 `0(n)`）按 PDF 改正并记下改了几处？

## 三、交付时怎么说

按这个顺序，三句话以内讲完：

1. **文件在哪**：译文绝对路径、符号表在译文开头第几行。
2. **校验结论**：公式 N 处全部逐字一致（或哪几处需人工）、结构对账通过、定理环境 X 条一致、术语 Y 条已统一。
3. **要人定的**：语义歧义、原文疑点、术语表里的 `待裁决` 项。给两种选择和各自后果，不要只说"请确认"。

不复述译文内容，不贴大段原文。

## 四、最容易漏的十处

按经验排序，逐条自查：

1. "其中 $C$ 只依赖于 $d$" → 译成"其中 $C$ 为常数"（丢了依赖关系）。
2. "with probability at least $1-\delta$" → 译成"大概率"（概率模式没了）。
3. `\|x\|_2` → `|x|`（范数变绝对值）。
4. `\le` → `<`（差一个等号，适用范围变了）。
5. Proposition → 定理（抬高结论等级）。
6. 脚注里的条件没译。
7. 表格里 `\|` 没转义，整行塌掉。
8. 符号表里 `\hat{f}` 抄成 `f`（读者以为是同一个量）。
9. 同一篇里 `consistency` 一处"相合性"一处"一致性"。
10. 原文编号 `(3)` 在译文里因为合并公式而错位，后面的交叉引用全错。
